# Everyday workflow coverage

This is a gap map against the **pinned Codex/Amplifier studies** cited in
[interaction reconciliation](INTERACTION-RECONCILIATION.md), not a claim of parity with
every feature in a current Codex release. Direction belongs to [VISION](../docs/VISION.md)
and contracts; verified scope belongs to [ACCEPTANCE](ACCEPTANCE.md).

| Workflow | Working path | Remaining gap |
|---|---|---|
| Learn and troubleshoot | Offline guide, local Help/check/support report, provider overlay wizard with named environment references and loadable YAML paths; confirmed standalone provider-access probe | OAuth/keychain migration, broader credential methods and cross-platform readiness |
| Read and inspect | Default inline terminal/tmux scrollback, retained transcript after exit, responsive Markdown tables, syntax highlighting, exact tool/code copy, fullscreen inspection; stable-projection character resize anchors and approximate unique table-cell matching | Ambiguous or otherwise structurally changed projections use explicit item fallback; inspection temporarily owns the alternate screen |
| Compose | Multiline/paste safety, directory recall, completion, immutable file/line and PNG/JPEG/static GIF/WebP sets, queues, thumbnails, external editor; bounded Linux clipboard MIME fallback and actual macOS CI PNG pasteboard gates | Physical-desktop/remote clipboard breadth; broader/animated formats |
| Keep working during a turn | Follow-up queue; pause/run/edit/remove; scoped steering with observed insertion; Stop holds pending work; confirmed uncertain-correction copy into an empty unsent draft | Interrupted-tool replacement and earlier uncertain effects cannot be reversed by copying a draft |
| Return | Canonical context, saved drafts, startup and in-app resume pickers, explicit historical recovery fork, composition/cwd validation | Exact interrupted-context repair, arbitrary module-private state |
| Organize | Names, paged pickers, incremental private full-text index, jump/copy; synthetic 100k-message index/search, complete catalog and native Resume paint measurements | Larger/cold-state breadth; exhaustive search beyond disclosed record/index bounds |
| Decide | Scoped approvals; direct question card, choice/free-text review, cancellation, child routing; scoped durable answer/correction/dialog copies | Last unflushed keystrokes; recovered copies never auto-submit |
| Change runtime behavior | Explicit setup/overlays; mode badge, retained provider/mode selection, named instances, vendor guard; advisory model discovery with bounded public limits/capabilities; confirmed public-context fork into a newly prepared provider composition | In-place arbitrary model changes, private-state conversion and vendor-specific message formats |
| Delegate | Scoped children/v2 recipes, approvals/questions/cancellation, refreshing child list, guarded completed/nested/routed continuation; explicit new-ID interrupted direct-child public adoption with supported simple/persistent contexts and fresh persistent storage, including legacy receipts with sufficient exact original-policy evidence | Arbitrary private/nested interrupted-state reconstruction, receipts without adequate original policy, subprocess isolation; crash-uncertain recipe effects |
| Review changes | Independent root/child outcomes; Git/diff/hunk review; confirmed conflict proposals; tool/agent-correlated source digests, unchanged-version links to preceding edits across resume, command return code and retained interrupted pre-effect evidence | Exclusive causal attribution, semantic test coverage, external-writer transaction and automatic conflict resolution not claimed |
| Inspect context | Explicit allowlisted context configuration and provider-reported catalog limits; observed usage/compaction, stored public messages, separate dispatch summaries, explicit memory-only provider-reported request projection and instruction-source index | Configuration/catalog limits are not effective request budget or occupancy; exact wire, missing/provider-redacted fields and non-reporting module sources |
| Recover | Fail-closed checkpoints/control records; no replay; source-scoped dialog copies; explicit uncertain follow-up dismissal; read-only historical child/action evidence | Last unflushed keystrokes; exact interrupted-context/module-private recovery |
| Perform | Native renderer, bounded projections/delivery, non-blocking writes, owned host process group and cooperative execution grace; latest integrated run reports no callback warnings; reproducible stress receipts and strict prepared-policy comparator | Policy-equivalent CLI latency, arbitrary cancellation edge cases, detached/remote cleanup and broader all-seam policy conformance |
| Install | Private pinned Git installation; published rc4 compiler-free wheels; five-platform native/installed-PTY gates including Ubuntu 22.04, actual Mac PNG pasteboard and exact CI ARM installed-live proof | Physical-terminal/live breadth beyond tested gates; musl; Git source install still needs Rust/linker |

The remaining high-value runtime work includes arbitrary cancellation/recovery boundaries,
stronger causal review, platform breadth and matched CLI measurements. Actual isolated
CLI/TUI preparation still finds different policy modules; renderer timing is not parity proof. Those need exercised
host/module seams, not controls that translate silently into something else. The current
native client remains Ratatui; OpenTUI is a historical comparator and Textual a test harness.
