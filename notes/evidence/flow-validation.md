# Continuous work and usage — development verification

Scope: FLOW-01..03, toward the amended DRAFT vision and presentation/interaction
contracts. App adapters and native renderer only; no kernel changes, publication,
personal-service mutation or complete CLI-parity claim. Existing local changes and
the checkout-following development launcher remain intact.

## Experience

- Immediate welcome/editable draft with named bundle, dependency, initialization,
  restoration and capability-discovery phases.
- A continuous chronological transcript using available height, without the eight-row
  live cap. Delegate summaries include task previews and observed child activity.
- Attributed per-call model/routing, local time, duration, cache-aware input/output/total
  and reported cost. Child calls contribute once to turn/session totals. Missing cost
  and unavailable legacy usage are disclosed; no routine billing/occupancy disclaimers.
- Native mouse copying remains default. Interact enables inline tool/thinking previews
  through clicks or Up/Down + Enter; Activity links expose nested observations and exact
  evidence. Escape restores native ownership without replay or losing the draft.

## Verification

The final integrated gate passes **620 tests in 312.99 seconds**, with native,
preset and independent module-swap gates enabled; no skips or warnings. Rust passes
39 tests in each of dark, light, terminal-default and NO_COLOR treatments; formatting,
strict Clippy, Ruff and the three OpenTUI harness tests pass.
Both real daily-launcher presets pass the final bounded live journey: one root turn,
four parallel delegates plus one recipe child, and 13 attributed model responses each.
Inline and recursive inspection, usage accumulation, draft retention and resume without
execution pass. All 44 runtime/renderer source fingerprints match the final checkout.
Successful disposable live projects were cleaned up.

Separate timing covers 30 alternating renderer-startup pairs and 18 streaming stress
cells. The nine native cells span 1,000/10,000/100,000 history items and 30/100/500
deltas per second: typing p95 is **21.6–34.6 ms**, event-to-visible p95 **20.9–39.1 ms**;
syntax-stress typing p95 is **24.8 ms**. Native first-usable composer median/p95 is
60.6/74.6 ms in the controlled scene, not bundle/provider startup. These are warm-file,
shared-host Linux PTY observations, not a matched-policy CLI or physical-device claim.
All 27 benchmark source fingerprints match the final checkout. Native history replay
initially projects the latest 1,000 items; retained source and subsequent output are not
capped. The OpenTUI comparator has different history projection and is not parity proof.
Controlled fixtures are not model-quality evidence. Raw terminal captures, owned live
state, journals and receipts remain private/ignored, not public example conversations.

The checks caught and corrected regressions: a transient startup phase must not
modify a checkpointed journal during a refused reopen, and action search must not confuse
Interact with Activity. Visual inspection then caught keyboard selection of hidden child
records; the added terminal assertion keeps expansion attached to a visible parent card.
Tests also cover retries/overlapping responses, nested progress without stray root cards,
typing during expansion, inline Activity links, three terminal sizes and native mouse return.
The first timing run exposed a roughly 300 ms streaming tail while typing stayed fast:
a completed replay backlog hid new work. The native projection now shows its unfinished
suffix while old rows drain in bounded batches. A Rust regression and the repeated
stress measurement cover the fix; failed-then-corrected receipts remain separate.

## Boundaries

Only app-observed operations can be named; opaque work inside an independent module
cannot be invented. Child activity is event-based, not a private reasoning trace.
Costs sum observed response reports; unreported or interrupted-call charges cannot be
reconstructed. No pricing lookup or provider billing reconciliation is performed.
Old terminal rows stay immutable; interactive expansion is a reflowed projection, not
in-place mutation of tmux history. A still-changing Markdown block cannot be committed
as immutable history until its structure is stable; inspection remains available.
Physical mobile keyboards/clipboards, other platform releases and policy-equivalent
CLI latency remain separate gates. No newly published wheel is implied.
The lightweight PTY observer does not model native history reflow on resize; its resized
primary-screen captures are not scrollback evidence. Six actual attached-tmux cases
verify retained history, native selection and a single composer after shrink/grow.
